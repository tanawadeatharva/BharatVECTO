## Fuel Cell Mass Flow Map (.vfcm)

File containing the fuel cell system mass flow map.

Contains entries for the fuel consumption in g/h depending on the power demand in kW

**Example:**

~~~
P_el_out [kW],	m_H2 [g/h]
30.0,	        2002.0
60.0,	        3003.0
105.0,	        5436.5
150.0,	        8662.5
195.0,	        12199.7
255.0,	        17017.0
300.0,	        21450.0
~~~
